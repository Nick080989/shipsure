# ShipSure privacy policy

Last updated: 11 November 2026

ShipSure is a Forge app for Jira that scores how ready a release is to ship.

## What data ShipSure uses

When you open the ShipSure project page or ask the ShipSure Rovo agent a question, the app reads these items from your Jira site:
- project versions
- issues in a release, with their summary, type, status, priority, assignee, last updated date and issue links

The data is read as you, so ShipSure only sees what you are allowed to see.

## What ShipSure stores

Nothing. ShipSure has no database or storage. Jira data is processed in memory to calculate the readiness report and is discarded when the request finishes. The app does not copy or cache personal data such as account IDs.

## Where it runs

ShipSure runs entirely on Atlassian Forge infrastructure. It makes no calls to any service outside Atlassian, and it does not use analytics, tracking or third-party services.

## What ShipSure writes

ShipSure writes to Jira only when you ask it to post a readiness report as a comment on an issue. The comment is posted as you.
